# 九九ビルダー！ブロック島（Kuku Builder: Block Island）

**「暗記」ではなく「組み立て」で覚える。**

かけ算九九をなかなか覚えられない小学校2年生以上の児童生徒を対象に、認知心理学と世界各国の算数教育アプローチを組み合わせて開発した、タイムプレッシャー・ゼロのWeb学習アプリです。

## なぜこのアプリを作ったのか（開発背景）

従来の九九アプリやドリルには、覚えられない子にとって大きな壁がありました。

* **日本の九九教育の課題**：音韻の丸暗記（「いんいちがいち…」）に頼りすぎると、ワーキングメモリへの負荷が高くなり、意味や数量感覚（「7が8こ分」という面積のイメージ）が育ちにくくなります。

* **海外の定番アプリの課題**：スピード競争型アプリは「算数不安（Math Anxiety）」を引き起こしやすく、タイムプレッシャーによってかえってやる気を失うケースが指摘されています。

そこで本アプリでは、「日本の九九の音韻リズム」×「世界の面積図（アレイ図）＆分配法則」×「クリエイティブな島づくり報酬」×「忘却曲線ベースの復習」を1つに統合しました。

## 主な機能

1. **制限時間・減点ゼロの「ブロックこうじょう」**

   * 答えが分からないときは、勘で答える必要はありません。

   * **✂️ ぶんかいハサミ（分配法則パズル）**：たとえば `7 × 8` を、自分の知っている `7 × 5 = 35` と `7 × 3 = 21` にパカッと分けて合体できます。

   * **🔄 くるりん回転（交換法則）**：`7 × 8` を90度回転させて `8 × 7` として考え直せます。

   * **👣 1列ずつかぞえる**：1列ずつハイライトしながら、音と数の増え方を確認できます。

2. **「じぶんの島」クリエイティブ報酬＆分散学習**

   * クリアした九九の面積が、そのまま「アイスクリームやさん」「かんらんしゃ」「うちゅうステーション」などの建物として自分の島に建ちます。

   * 忘却曲線に基づき、時間が経った九九や苦手な段が「きょうの けんちくクエスト」として自然に再登場します。

3. **🎵 リズムステップ（音感モード）＆ 🗺️ 81マス九九ずかん**

   * Web Speech API（日本語音声）と Web Audio API（マリンバ風音階）を同期させ、視覚と聴覚の両方から九九のリズムを定着させます。

   * 全81マスの定着マップで、「自力でマスター（⭐）」と「分解パズルでクリア（🔨）」が一目で分かります。

4. **📊 おうちの人・先生向け 学習サポートレポート**

   * 単なる正答率だけでなく、「分解パズルを何回使って自力で解いたか」「くるりん回転を何回活用したか」など、思考のプロセスを可視化します。

## GitHub Pages へのデプロイ手順

このアプリは **完全な単一HTMLファイル（バックエンド不要）** で動作するため、GitHub Pages で数分で無料公開できます。

1. **リポジトリを作成する**

   * GitHub にログインし、新しいパブリックリポジトリ（例：`kuku-builder-island`）を作成します。

2. **ファイルをアップロードする**

   * `kuku_builder.html` を **`index.html`** にリネームし、リポジトリのルート（一番上の階層）にアップロード（または `git push`）します。

   * 合わせて `readme.md`（または `README.md`）や `manual.pdf` も同じフォルダに置くと便利です。

3. **GitHub Pages を有効にする**

   * リポジトリの **Settings** タブを開き、左メニューの **Pages** をクリックします。

   * **Build and deployment** の **Source** で `Deploy from a branch` を選択します。

   * **Branch** で `main`（または `master`）と `/ (root)` を選び、**Save** を押します。

4. **公開URLにアクセスする**

   * 1〜2分待つと画面上部に `https://<あなたのユーザー名>.github.io/kuku-builder-island/` というURLが表示されます。タブレットやPC、スマートフォンのブラウザからそのまま遊べます。

## 動作環境・技術仕様

* **対応環境**：PC・iPad・タブレット・スマートフォンのモダンブラウザ（Chrome / Safari / Edge）

* **使用技術**：HTML5 / Tailwind CSS (CDN) / Vanilla JavaScript / Web Audio API / Web Speech API / `localStorage`（学習記録は端末内にのみ自動保存され、外部サーバーへ送信されません）
